## この本が目指すもの（一行）

> 思い通りにならない人生を、それでもどう生きるか。

※これは **仮説**。PHASE 5 で全投稿分析後に確定する。今の段階でこれを結論として扱わない。

---

## 絶対原則：教えない

書いてよいもの / 書いてはいけないもの。

| ✕ 書かない | ○ 書く |
| --- | --- |
| 「人生とはこういうものです」 | 主人公にそう思わせる出来事 |
| 「こう考えるべきです」 | 主人公が迷っている時間 |
| 「だからこうしましょう」 | 主人公が選んだ行動と、その結果 |
| 教訓の要約 | 読者が要約したくなる余白 |

流れは常にこの順序：

```
出来事 → 感情 → 迷い → 問い → 誰かとの会話・発見 → 主人公自身の気づき
```

**読者に答えを渡さない。読者自身に答えを見つけてもらう。**

## なのさの文章の手触り（本文を書くときのチェック）

- [ ] 一文が短いか
- [ ] 改行による余白があるか（読者が考える時間）
- [ ] 中高生に届く言葉か
- [ ] 人生論からではなく、具体的な出来事から始まっているか
- [ ] 「普通はこう考えるけれど、もしかしたら違うかもしれない」という視点の反転があるか
- [ ] 断定しすぎていないか
- [ ] 読み終わりに少し心が動くか

目指すのは **物語の厚み × 心晴日和の言葉**。
短文をそのまま並べない。しかし言葉の手触りは残す。

## 読後感の目標

「人生は素晴らしい！」でもなく、「人生は不幸だ」でもない。

> 人生には、どうにもならないことがある。
> それでも、この人生を生きていこう。

そして、

> 明日の朝、少しだけ違う景色が見えるかもしれない。

---

## 主人公について

なのさ本人にしない。読者が自分を重ねられる人物にする。

設定を細かくするより、心の動きを決める。

| 項目 | 内容 |
| --- | --- |
| 欲しいもの（want） | 未定（PHASE 6） |
| 本当に必要なもの（need） | 未定 |
| コンプレックス | 未定 |
| 恐れているもの | 未定 |
| 最初の人生観 | 未定 |
| 最後の人生観 | 未定 |
| 失うもの | 未定 |

物語の中心は出来事ではなく、**出来事によって心がどう変化するか**。

---

## 急がないこと（自戒）

1. いきなり本を書き始めない。
2. 数百本読んだ段階で章立てを決めない。
3. 「人生とは不幸なものである」を最初から結論に固定しない。
   - これは検証対象であって、前提ではない。
   - 反証を探すことを、分析手順に組み込む（`docs/02_分析の方法.md`）。
4. きれいな言葉より、本当に思っていることを優先する。
