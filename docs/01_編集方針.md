# 編集方針

引き継ぎ書から、作業中に何度も参照するものだけを抜き出したもの。
原文は `docs/00_引き継ぎ書.md`。迷ったら原文に戻る。

---

## この本が目指すもの（一行）

なのさ自身の言葉（2026-08-29）：

> **人生は不幸でも良い。そう思えるか。**

引き継ぎ書の時点の仮説（「思い通りにならない人生を、それでもどう生きるか」）より、
こちらを採る。理由は、**これが断定ではなく問いだから。**

```
人生とは不幸なものである    → 世界についての断定。読者に教える文。
人生は不幸でも良い。       → 読者への問い。読者自身が答える文。
そう思えるか。
```

前者を核にすると、引き継ぎ書 8. の「教えない」原則と正面から衝突する。
後者なら衝突しない。**答えは読者の中にしかない。**

※まだ **仮説**。PHASE 5 で確定する。ただし出発点はこの一文にする。

## 絶対原則：教えない

書いてよいもの / 書いてはいけないもの。

| ✕ 書かない | ○ 書く |
| --- | --- |
| 「人生とはこういうものです」 | 主人公にそう思わせる出来事 |
| 「こう考えるべきです」 | 主人公が迷っている時間 |
| 「だからこうしましょう」 | 主人公が選んだ行動と、その結果 |
| 教訓の要約 | 読者が要約したくなる余白 |

流れは常にこの順序：

```
出来事 → 感情 → 迷い → 問い → 誰かとの会話・発見 → 主人公自身の気づき
```

**読者に答えを渡さない。読者自身に答えを見つけてもらう。**

### 自覚しておく緊張関係

思想の出どころは執行草舟（`docs/07_思想の源泉_執行草舟.md`）。
執行草舟の語り口（断定する・教える）と、心晴日和の語り口（押しつけない・教えない）は、
おそらく正反対である。

この緊張は、なのさ自身の言い方（「不幸 **でも良い**。そう思えるか」）で
ほぼ解けている。**ただし書いている最中に、断定のほうへ滑り落ちる危険は残る。**

**この本が失敗するとすれば、ほぼ確実にここで失敗する。**
思想の強さに引きずられて語り口が崩れ、説教臭くなる。

書きながら定期的に自問する：
**いま書いているこの一行は、なのさの言葉か、それとも執行草舟の言葉か。**

そして——**「良い」を落としていないか。**
「人生は不幸だ」と書いた瞬間に、この本は別の本になる。

### 思想の三層

なのさから出た三つの言葉は、層になっている（`docs/09_絶対負.md`）。

| 層 | 言葉 | 担うもの |
| --- | --- | --- |
| 構造 | **絶対負** | 生命の根源にある負のエネルギー。失うこと・捧げることに本質がある |
| 質感 | **悲哀** | 人生の手触り |
| 問い | **不幸でも良い。そう思えるか** | 読者に手渡すもの |

### ★★ 「良くなる」と書かない

執行草舟は **「希望」を悪徳とする。**「まだ大丈夫」「何とかなる」が人類を滅ぼす、と。
一方、目指す読後感は「明日の朝、少しだけ違う景色が見えるかもしれない」（引き継ぎ書 17.）。

**この二つは、書き方ひとつで衝突もするし、しない。**

```
✕ 明日は、きっと良くなる。            → 希望。執行草舟と衝突する
✕ いつか報われる日が来る。            → 絶対負の否定
✕ 大丈夫、何とかなる。                → 名指しで批判されている言い方

○ 明日の朝、同じ景色が違って見えるかもしれない。   → 何も良くなっていない
○ それでも、この人生を生きていこう。               → 報酬の約束がない
```

**世界は変わらない。見る側が変わる。**
これはなのさが1193本で繰り返してきた形でもある（引き継ぎ書 11.「視点を反転させる」）。

**希望では終わらせない。憧れで終わらせる。**
詳細と検討中の論点は `docs/10_希望という問題.md`。

### 主人公は、失うことで輝く

絶対負は「借り」ではなく、**燃やして失うためのエネルギー**。
得ることではなく、失うこと・捧げることに生命の本質がある。

引き継ぎ書 7. の「何を失うのか」は、設定項目のひとつではない。
**それが物語の主題そのもの。**

```
主人公は失う。そして、失うことによってしか輝かない。
```

**絶対負そのものは書けない。しかし「失うこと」「捧げること」は書ける。**

### ★ 絶対負は、伝達しない。翻訳する。

執行草舟は、苦悩を知る大人に、強い言葉で正面から書く。
なのさは、13歳に、朝の短い文章で書いてきた。

絶対負をそのまま14歳に渡すと、**「自分には価値がない」と読まれる。**
思春期には、その読み方のほうが自然に届いてしまう。

同じ思想でも、渡し方でこうなる：

> 幸せでいなければならない義務なんて、誰も背負っていない。
> うまくいかない日があっても、あなたが失敗しているわけじゃない。

**思想はそのまま受け取る。語り口は一切持ち込まない。**
本文を書きながら自問する：**これは執行草舟の声か、なのさの声か。**

### 絶対負を説明させない

絶対負は抽象概念で、場面が無い。油断すると
**登場人物の誰かが主人公に人生を教え始める。**
引き継ぎ書 8. がいちばん禁じている形であり、いちばん陥りやすい形。

説明ではなく、反転で見せる：

```
どうして自分だけ、奪われるのか
        ↓
どうして自分に、与えられていたのか
```

新しい情報は要らない。誰も説明しない。主人公が気づくだけでいい。

### 「悲哀」は「不幸」ではない

なのさの言葉は「人生は **悲哀** に満ちている」。

| | 不幸 | 悲哀 |
| --- | --- | --- |
| 何か | 判断（悪いことが起きた） | 感触（かなしみが満ちている） |
| 扱い | なくしたい | なくせない。感じるもの |
| 美しさ | ない | ある |

本文で使う言葉は、できるだけ **悲哀の側** に寄せる。
中高生に手渡せるのは、おそらくこちらのほう。

## 読後感の目標

「人生は素晴らしい！」でもなく、「人生は不幸だ」でもない。

> 人生には、どうにもならないことがある。
> それでも、この人生を生きていこう。

そして、

> 明日の朝、少しだけ違う景色が見えるかもしれない。

## 主人公について

なのさ本人にしない。読者が自分を重ねられる人物にする。

設定を細かくするより、心の動きを決める。

| 項目 | 内容 |
| --- | --- |
| 欲しいもの（want） | 未定（PHASE 6） |
| 本当に必要なもの（need） | 未定 |
| コンプレックス | 未定 |
| 恐れているもの | 未定 |
| 最初の人生観 | 未定 |
| 最後の人生観 | 未定 |
| 失うもの | 未定 |

物語の中心は出来事ではなく、**出来事によって心がどう変化するか**。

## 急がないこと（自戒）

1. いきなり本を書き始めない。
2. 数百本読んだ段階で章立てを決めない。
3. 「人生とは不幸なものである」を最初から結論に固定しない。
   - これは検証対象であって、前提ではない。
   - 反証を探すことを、分析手順に組み込む（`docs/02_分析の方法.md`）。
4. きれいな言葉より、本当に思っていることを優先する。
