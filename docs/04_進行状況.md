  446字超の27本に promise は **0本**。促しの短文だけが「良くなる」と言う。
  → `docs/10` に結論を追記。**本は長いモードで書けば、執行草舟と衝突しない。**
- **★★ 報われなさに、必ず見返りがつく。** 39本で例外なし。
  → `docs/11` 第2回。**本が引き受ける最後の一歩が決まった。**

  → 終わらない痛みは書けない。悲哀は終わらない。だから1668回書かれなかった。

  → `docs/09` Q12 の答えの一つ。執行草舟の「愛＝自己犠牲」は取らない。
- Day1643（39本で最短・143字）「恐れずに。いや、恐れながらも。」
  → **負の感情を回収せずに残した、39本で唯一の行。**

**同日、なのさから二つの決定的な訂正があった。**

1. Day1643 で恐れを置いていけたのは「短いから」ではなく **「抽象だから」**。
   → 抽象の痛みは痛くない。具体の中では一度も置けていない。
2. 心理に触れない理由は **「朝、元気づけ、勇気づけの文章だから」**。
   → **空白は書けなかったものではなく、書かないと決めていたもの。**
3. そして——**「物語は具体です。具体の中で書いていくということ。」**

→ `docs/12_具体と抽象.md` を新設。**本文の書き方が決まった。**
→ `tools/abstraction.py` を追加。段落ごとに具体／抽象を測る。

   最後まで一般化しなかった8本（Day1638 ほか）が、本文の手本になる。
→ **1668本の「でも」の位置が、この本の章の位置になる。**
