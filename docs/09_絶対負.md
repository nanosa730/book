# 絶対負

なのさの意向（2026-08-29）：

> 執行草舟の絶対負の思想も混ぜ合わせながら、この本では表現していきたい。

---

## なのさによる説明（2026-08-29）

**一次資料。編集室の当初の理解は誤っていたので、こちらを正とする。**

> - 「絶対負」とは、生命の根源にある宇宙エネルギーのこと。
>   そこから「人間は死ぬために生きている」という死生観が導かれます。
> - 宇宙の根源エネルギーは本来「負（マイナス）」であり、生命はそれを燃焼させることで輝く。
>   得ること・満たされることではなく、失うこと・捧げることに生命の本質があるという発想です。
> - したがって現世で報われない生き方こそ真実の人生とされます。
>   成功や健康のための努力は、この立場からは本末転倒になります。
>
> **そこから出てくる現代批判**
>
> - 既成宗教は「良いことしか言わない死に体」であり、
>   本来「死ぬために」行っていた坐禅などの修行が「良くなるため」の手段に堕した、と批判します。
> - 「希望」を悪徳とみなす点も特徴で、
>   「まだ大丈夫」「何とかなる」という希望こそが人類を滅ぼす、と説きます。

### 編集室の当初の理解は、どこが違っていたか

記録として残す。同じ間違いを繰り返さないため。

| | 誤（当初の理解） | 正 |
| --- | --- | --- |
| 絶対負とは | 与えられたものへの**借り**。負債 | **生命の根源にある宇宙エネルギー**そのもの |
| 負の意味 | 人間の立ち位置がマイナス | **エネルギーが本来マイナス** |
| 生の目的 | 返しきれない借りを引き受ける | **燃焼させる。失う。捧げる** |
| 報われなさ | 受け入れるべきもの | **それこそが真実の人生** |
| 死 | （考えていなかった） | **人間は死ぬために生きている** |

「借り」と読むと、**返そうとする物語**になる。方向が逆だった。
正しくは、**失うことで輝く物語**。

---

## 物語にとって、これは追い風になる

意外に聞こえるかもしれないが、この訂正で **物語は作りやすくなった。**

「借り」は抽象概念で、場面にならない。
しかし **「失う」は、そのまま場面になる。**

引き継ぎ書 7. には、主人公に決めるべきこととして
すでに **「何を失うのか」** が入っている。

訂正前：それは物語の一要素だった。
訂正後：**それが物語の主題そのものになる。**

```
主人公は失う。
そして、失うことによってしか輝かない。
```

「燃焼」も同じ。燃焼は場面になる。何かに打ち込んで、すり減って、
返ってこない——それは書ける。

**絶対負そのものは書けない。しかし「失うこと」「捧げること」は書ける。**
物語への変換口は、ここにある。

## 三つの言葉が、きれいに噛み合っている

なのさから出てきた三つの言葉は、ばらばらではない。層になっている。

| 層 | 言葉 | 何を担うか |
| --- | --- | --- |
| **構造** | **絶対負** | **なぜ「不幸でも良い」と言えるのか。その理屈** |
| **質感** | **悲哀** | 人生はどんな手触りをしているか |
| **問い** | **人生は不幸でも良い。そう思えるか** | 読者に手渡すもの |

とくに、**絶対負が核の一文の理屈になっている** ことが大きい。

```
なぜ、不幸でも良いと言えるのか。

生命は、もともと負のエネルギーだから。
満たされるためではなく、燃やして失うためにあるから。
報われることなど、はじめから予定に入っていないから。

だから不幸は、失敗ではない。予定通りですらある。
```

**「どうして自分だけ」が成立しなくなる。** そこが出発点になる。

そして引き継ぎ書 6. の心理変化には、すでにこのステップがある。

```
うまくいかない → 苦しくなる → 「どうして自分だけ」と思う → …
```

**絶対負は、この「どうして自分だけ」に対する答えとして働く。**
偶然ではなく、構造が噛み合っている。

## ★ 正直に言っておきたいこと：この本は誰の本か

順番を並べると、こうなっている。

```
引き継ぎ書：1193本の奥から、なのさ自身も気づいていなかった思想を発見する
   ↓
本の核の出どころは、執行草舟だった
   ↓
その核は、1193本のどこにも書かれていない
   ↓
さらに「絶対負」も混ぜたい
```

**いま、1193本から三歩離れたところにいる。しかも、まだ一本も読んでいない。**

これは反対ではない。執行草舟を土台にした本を書くのは、まったく正当な選択で、
なのさが決めることだ。ただ引き継ぎ書 16. に、こう書いてある。

> 「それは本当に、なのさが伝えたいことですか？」

だから一度だけ聞いておきたい。

> **この本は「執行草舟の思想を、なのさが語り直す本」ですか。**
> **それとも「なのさの本」で、執行草舟はその土台ですか。**

どちらも良い本になる。だが **別の本** になる。
主人公も、章の順番も、最後の一行も変わる。

## こちらの答え（仮説）：なのさの持ち分は「翻訳」

上の問いに、編集室としての見立てを先に書いておく。

執行草舟は、苦悩を知っている大人に向けて、強い言葉で正面から書く。

なのさは中学校の教員で、**13歳から16歳に向けて、毎朝短い文章を書いてきた。**

絶対負を、そのまま14歳に渡したらどうなるか。

> 「お前は何も持っていない。すべて借りものだ。何も期待するな。」

**これは、まず間違いなく別の意味で受け取られる。**
自分には価値がない、と読まれる。思春期には、その読み方のほうが自然に届く。

しかし、同じ思想が、渡し方ひとつでこうなる。

> 「幸せでいなければならない義務なんて、誰も背負っていない。
> 　うまくいかない日があっても、あなたが失敗しているわけじゃない。」

**同じ絶対負。正反対の着地。**

そして、この翻訳ができるのは執行草舟ではない。彼は13歳に教えていない。
**なのさにしかできない。1193本は、その翻訳の練習記録だ。**

だから編集室の方針はこうなる。

> **絶対負は、伝達するのではなく、翻訳する。**
> 思想はそのまま受け取る。語り口は一切持ち込まない。

## 物語にするときの、具体的な難所

**絶対負には、場面が無い。** 抽象概念だからだ。

このまま物語に入れようとすると、必ずこうなる——
**登場人物の誰かが、絶対負を説明し始める。**
賢い大人が出てきて、主人公に人生を教える。
引き継ぎ書 8. がいちばん禁じている形であり、いちばん陥りやすい形でもある。

だから、先に決めておく問いはこれ。

> **絶対負を、どの出来事に変換するか。**

現時点の候補（すべて仮）：

| 場面 | 何が起きるか |
| --- | --- |
| **何かを失う。返ってこない** | **燃焼。絶対負そのもの** |
| **報われないと分かっていることに、打ち込む** | **捧げる** |
| 得たと思っていたものが、失うための準備だったと分かる | 方向の反転 |
| **「どうして自分だけ」が反転する** | **下記** |

最有力は、最後のもの。

```
どうして自分だけ、奪われるのか
        ↓
どうして自分に、与えられていたのか
```

**問いの向きが変わるだけで、同じ出来事の意味が裏返る。**
新しい情報は要らない。誰も説明しない。主人公が気づくだけでいい。

これは引き継ぎ書 11. の「視点を反転させる」——
なのさが1193本で繰り返してきた形そのものでもある。

**思想は執行草舟のもの。しかし反転のさせ方は、なのさのもの。**
その一点で、この本はなのさの本になる。
