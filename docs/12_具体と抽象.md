## 1．なぜ抽象だと、痛みを置いておけるのか

```
抽象 → 痛みが痛くない → 回収しなくていい
具体 → 痛みが痛い   → 回収せずにいられない
```

Day1643 の「恐れ」は、**誰の、何に対する恐れでもない。** 一般名詞としての恐れ。
だから「恐れながらも」で置いていける。**痛まないから。**

これは39本のデータと完全に一致する。

| Day | 具体か抽象か | 痛みの扱い |
| --- | --- | --- |
| 1650 撤退 | **具体**（自分が、白馬で、その朝） | 「悔しい」→ 一行で回収 |
| 1638 無人島 | **具体**（自分が、無人島で、14時） | 恐怖が持続 → 船が来て解決 |
| 1643 恐れ | **抽象**（誰でもない、いつでもない） | **回収せずに置けた** |

**具体の中では、なのさは一度も痛みを置いていけていない。**

## 2．「でも」の正体

`docs/11_空白の地図.md` に「報われなさに必ず見返りがつく」と書いた。
なのさの答えで、その仕組みが分かった。

**見返りをつけていたのではない。抽象へ上がっていた。**

```
悔しい。                    ← 具体。痛い
もちろん そう思います。
でも                        ← ★ここが階段
「頂上まで行くこと」だけが
登山ではない。               ← 抽象。痛くない
```

**「でも」は、具体から抽象への階段だった。**
上がれば痛くない。だから上がる。1668回、そうしてきた。

**そして、それは朝の文章として正しい。**
読者を痛いところに置き去りにしないための、正しい配慮である。

## 2.5　なぜ上がるのか —— 本人の答え（2026-08-29）

> **朝、元気づけ、勇気づけの文章ですから、心が前向きになるように、心理には触れません。**

**空白は、書けなかったものではない。書かないと決めていたもの。**

編集室はこれまで、なのさが痛みに留まれない理由を三度推測して、三度外した。

| 推測 | 結果 |
| --- | --- |
| 字数のため | ✕ |
| 読者への配慮（漠然と） | △ 方向は合っていたが浅い |
| 短いから意味づけの余地がない | ✕ |
| **朝の文章は元気づけ・勇気づけであり、前向きにするために心理に触れない** | **○ 本人の答え** |

つまり、なのさが守ってきたルールはこれだった。

```
感情の名前は書く。   （「悔しい」「怖かった」）
その中には入らない。 （なぜ悔しいのか。悔しさは何でできているのか）
```

**1668回、このルールを守り抜いてきた。**

### そして、この本は逆をやる

引き継ぎ書 7. にこう書いてある。

> 物語の中心は出来事ではなく、**出来事によって主人公の心がどう変化するか**

**それは、なのさが1668回、意図的に触れなかったところそのもの。**

```
心晴日和：出来事 →（心理を飛ばして）→ 意味 → 前向き
この本　：出来事 → 心理 → 心理 → 心理 →（意味は読者が作る）
```

**「でも」は、心理を飛び越すための踏み台だった。**

### ★★★ だから、章の位置が決まる

**1668本の「でも」の位置が、この本の章の位置になる。**

なのさが「でも」と書いて上がったところ——そこに、書かれなかった心理がある。
本は、その一段を、何ページもかけて降りていく。

例：Day1650

```
悔しい。
もちろん そう思います。
でも                        ← 1668本ではここで上がった
                            ← 本では、ここから何ページも続く
「頂上まで行くこと」だけが
登山ではない。
```

## 3．だから「教えない」の意味が変わる

引き継ぎ書 8. の絶対原則——**教えない。**
これまで方針として持っていたが、実行方法が分からなかった。

**いま分かった。**

```
教える  ＝ 抽象へ上がる
教えない ＝ 抽象へ上がらない。具体のまま置く
```

「人生とはこういうものです」は抽象。
「こう考えるべきです」は抽象。
**教訓とは、抽象そのもののこと。**

だから——

> **教えない本を書くとは、抽象へ上がらない本を書くということ。**

引き継ぎ書 8. は、態度の話ではなく **文体の話** だった。

## 4．そして、物語は具体である（なのさの言葉）

> でも、物語は具体です。具体の中で書いていくということ。

**物語には、抽象へ上がる場所がない。**
主人公は「人生とは」と考えない。歩き、見て、言い、黙る。

つまり——

> **本を書くとは、なのさが1668回一度もやらなかったことを、やるということ。**
>
> **具体の中で、痛みを回収せずに置く。**

これがこの本の、いちばん難しいところ。**そして、いちばん価値のあるところ。**

## 5．具体に留まる技術（作業規則）

痛い場面では、以下を守る。

### 使わない

- 感情の名前（悔しい、悲しい、怖い、嬉しい）
- 「〜ということ」「〜というのは」「つまり」「だからこそ」
- 「〜かもしれません」「〜なのだと思います」
- 「人生」「私たち」「人は」「大切」「意味」「価値」「成長」
- **「でも」「けれど」で始まる意味づけの段落**

### 使う

- 時刻、数、天候、物の名前
- 身体（手、足、息、汗、喉、指先）
- 動作（歩いた、置いた、見た、黙った）
- 会話。ただし、答えを言わせない
- **考えの実況**（結論ではなく、頭に浮かんだ順に）

### 手本は Day1638 の、この部分

```
木はあるから
筏でも作って脱出するのか。

どうやって木を切るんだ
何で木を結ぶんだ。
```

**抽象語がひとつも無い。時刻と、木と、切る、結ぶ。**
39本のうち、具体が最も長く続いた場所であり、いちばん生きている場所。

そして直前——

```
14時を過ぎると
風は強くなり
波も高くなり
```

**時刻・風・波。** 恐怖という語を使わずに、恐怖が上がっていく。
**そのあと「その恐怖心もだんだん大きくなりました」と抽象へ戻った瞬間、温度が下がる。**

## 6．測る

`tools/abstraction.py` で、投稿の段落ごとに具体／抽象を判定できる。

```bash
python3 tools/abstraction.py --day 1650     # 「でも」の階段が見える
python3 tools/abstraction.py --day 1638     # 具体が続く場所が見える
python3 tools/abstraction.py --summary      # 全投稿の抽象度
```

**本文を書いたあとにも、これを通す。**
痛い場面で抽象へ上がっていたら、書き直す。

判定は語のマーカーによる粗いもので、正解ではない。**目安として使う。**

### 測定結果（39本／2026-08-29）

```
一般化する回：31本／一般化しない回：8本
一般化する位置の中央値：34%
```

**なのさは、投稿の3分の1あたりで、その出来事の話をやめる。**
そこから先は「人生」「私たち」「人は」の話になる。

最も早い例：
- Day1641（AI半導体）　86段落中 **2段落目**で一般化
- Day1665（手に入れたい／嫌を避ける）　31段落中 **1段落目**
- Day1656（iPhone）　24段落中 **1段落目**

### ★ 最後まで一般化しなかった8本 —— これが本文の手本

```
Day1638（無人島・82段落）  ← 39本で最長。一度も上がらない
Day1630（三国志・55段落）
Day1642（6つのリスト・48段落）
Day1631, Day1655, Day1664, Day1643, Day1658
```

**Day1638 は82段落あって、一度も「人生」へ行かない。**
だから恐怖が持続できた。docs/11 で「終わった恐怖だから書けた」と書いたが、
**具体が途切れなかったから書けた、のほうが正確。**

**本文を書く前に、この8本を読む。**

## 7．残る問い

- **なのさは、具体の中に留まっていられるか。**
  「抽象であれば書きやすい」とは、裏を返せば **具体は書きにくい** ということ。
  書きにくさは、痛いからかもしれない。
- 抽象へ上がらずに書いた文章を、中高生は読めるか。
  意味を言わない文章は、読者に委ねる量が多い。
- **「具体だけはほとんどない」** ——
  では、なのさが具体だけで書いた回は、1668本のどこかに一本でもあるか。
  **あるとすれば、それが本の最初の一行になる。**
