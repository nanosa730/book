### 19本すべてに「触れなかったこと」があった

そして、**ほとんどが同じものだった。**

| Day | 触れかけて、触れなかったこと |
| --- | --- |
| 1650 | 悔しさ。一行で「でも」に移る |
| 1651 | 失ったものの手触り。素敵な一日で上書きされる |
| 1652 | 動けないことの苦しさ。すぐ解決法へ |
| 1653 | 太陽を追わなくなることの、諦めや衰えの面 |
| 1654 | **死。悲しみ。大好きだった祖父母を失ったときのこと** |
| 1655 | 報われないことの寂しさ、不当さ |
| 1656 | 壊れたiPhone。損失は笑い話で流れる |

| 1662 | 学んでも変えられなかった授業 |

### 空白の正体：**痛みの持続時間**

なのさは、痛みを書かないのではない。**書く。しかし、すぐ意味づけに移る。**

```
悔しい。

もちろん
そう思います。

でも                 ← ここまで、たった一行
```

**痛みが文中に存在していられる時間が、極端に短い。**

「割愛しますが」（1666）は、その最も見えやすい跡。
被害の話に入りかけて、自分で飛ばしている。

### ★ なぜ短いのか —— 本人に聞いた（2026-08-29）

編集室は二つ推測した。**字数のためか。読む人への配慮か。**
**どちらも外れていた。**

Day1650 について、なのさの答え：

> **書きたいことあったが、まとまり決まらなかった。**

つまり——

```
避けていたのではない。
配慮でもなかった。
その朝、まだ形にならなかった。
```

**これは、空白の理由として決定的に重い。**

「心晴日和」は毎朝出す。**締切がある。**
だから書けるのは、**その朝までに意味づけが完了したものだけ。**

そして、**痛みは、その朝にはまとまらない。**

### だから、1668本は「まとまったこと」の全記録である

```
まとまった  → 書かれた   → 1668本になった
まとまらない → 書かれなかった → どこへ行ったのか
```

**なのさの中に残っている。**

Day1651（撤退の翌日）が深くなったのも、これで説明がつく。
一日待てば、少しまとまった。
**しかし一日でも足りなかった部分は、そのまま残された。**

1668回、毎朝、まとまったものだけが出ていった。
**まとまらなかったものは、一度も出ていない。**

### これが、本の材料である

> 心晴日和：**まとまったこと** を、その朝に書いたもの。1668本。
> この本　：**まとまらなかったもの** を、時間をかけて書くもの。

引き継ぎ書 8.（教えない）とも、ここでつながる。

| | まとまったこと | まとまらなかったこと |
| --- | --- | --- |
| 結論 | 出ている | 出ていない |
| 書ける形式 | 朝の短い文章 | **物語** |
| 読者への働き | 教えられる | **一緒に迷うしかない** |

**「教えない本」を作るには、「まとまらなかったもの」を材料にするしかない。**
まとまっているものは、書けば必ず教訓になる。

### だから、本が引き受ける領域が決まる

なのさは言った——「文字だけで伝えるのが難しいので、扱ってきていない」。

**この19本が示しているのは、それが「話題を避けた」のではないということ。**
話題には触れている。死にも、失敗にも、恐れにも触れている。
**避けているのは、そこに留まる時間のほうだった。**

そして「悲哀」とは、出来事ではなく **満ちている質** ——
つまり **持続するもの**（`docs/08_なぜ物語でなければならないか.md`）。

```
朝の短い文章は、持続を書けない。
物語は、持続を書ける。
```

**本が引き受けるのは、新しい話題ではない。同じ話題の、長い時間のほうである。**

主人公が痛みの中にいる時間を、なのさが1668回とれなかった長さでとる。
それが、この本にしかできないこと。

### 傍証：一日置くと、深くなる

Day1650（撤退した日）と Day1651（その翌日）は、同じ出来事について書かれている。

- **1650**：「悔しい」→ 一行で「でも」→「次の一歩を踏み出すための大切な選択」と回収
- **1651**：「夢や目標は実現できなくてもいいんだよ **という意味とは少し違って**」
  → **安易な慰めを、自分から拒否している**

**一日置くと、なのさは慰めを拒否できる。**
その日の朝には、まだできない。

`strength` も 1650 が 4、1651 が 5。**翌日のほうが強い。**

→ **物語は、出来事の翌日から書くべきかもしれない。** 検証を続ける。

## ★ 取材の方針が変わる

まとまらなかったものは、**定義上、投稿には書かれていない。**
過去投稿をいくら読んでも出てこない。

**だから、なのさに直接聞くしかない。**

`strength` 4〜5 の回、`unsaid` が濃い回について、必ずこれを聞く：

> **「この回、書けなかったことはありますか。」**
> **「いま、まとまっていますか。」**

そして——

**何年も、まとまらないまま残っているものがあれば、それが本の核に最も近い。**

分析レコードに `testimony` 欄を追加した（`analysis/schema.md`）。
なのさ本人から得た証言だけを書く。編集室の推測は `unsaid` のまま分ける。

## 第2回　Day1630〜1649（20本）　2026-08-29

### 訂正：なのさは、痛みに留まれる

第1回で「痛みが文中に存在していられる時間が極端に短い」と書いた。
**Day1638（無人島でスマホが壊れた回）が、これを崩す。**

```
14時を過ぎると
風は強くなり
波も高くなり

その恐怖心も
だんだん
大きくなりました。
```

**恐怖が、時間とともに増大していく描写。持続している。**
39本で唯一。

では、なぜこの回だけ書けたのか。

**すでに終わっていたから。**
無事に船が来て、家に帰って、PCから書いている。
**安全な場所から、終わった恐怖を振り返っている。**

対して Day1650（撤退）は、**その日の朝に、麓から書いている。**
まだ終わっていない。だから「まとまり決まらなかった」（本人証言）。

```
終わった痛み   → 書ける。長く留まれる
終わらない痛み → 書けない
```

**そして本の核は、終わらない痛みの側にある。**
悲哀とは「なくせない」もの、満ちている質（`docs/08`）。
終わりが来ないから、いつまでも「まとまらない」。

**だから1668回、一度も書かれなかった。**

### ★★★ もっと深い空白：報われなさに、必ず見返りがつく

39本を通して、はっきりした癖がある。

**なのさは報われなさを肯定する。しかし、必ず理由をつける。**

| Day | 報われないこと | つけられた見返り |
| --- | --- | --- |
| 1650 | 山頂に届かなかった | **「次の一歩を踏み出すための」大切な選択** |
| 1635 | 龍馬は名を求めず33歳で死んだ | **「欲しがらなかった人の名前が結果として歴史に残った」** |
| 1641 | 半導体を奪われた | **「足りないから賢くなれる」** |
| 1648 | 感謝も評価もされない | **「貢献感は自分の内側に残る」** |
| 1655 | 誰にも褒められず水をやる | **「そんな力って本当に素敵だな」** |
| 1636 | — | 「今日も成長すれば助かる人がきっと増えるから」 |

**39本のうち、報われなさを、報われなさのまま置いた回は、一本も無い。**

必ず最後に、何かが返ってくる。
賢くなる、貢献感が残る、歴史に残る、次につながる、誰かが助かる。

そして、これは **朝の文章として正しい。**
中高生に「報われないまま終わる」とは言えない。言うべきでもない。

### しかし、執行草舟の絶対負は、そこに見返りをつけない

> **現世で報われない生き方こそ真実の人生。**

理由も、見返りも、無い。**報われないことが、それ自体で真実である。**

Day1641 は「ない」を肯定するが、理由は **「そのほうが賢くなれるから」**。
これは有用性による正当化であり、執行草舟が本末転倒と呼ぶものに近い。

```
なのさ　：報われない。 でも、○○が残る。
執行草舟：報われない。 それが真実である。
```

**この「でも」の一語が、1668本と、この本の境界線。**

### だから、本が引き受ける最後の一歩が決まった

> **報われなさを、報われなさのまま置くこと。**

主人公は失う。取り返さない。意味づけもされない。
それでも生きる。

**その一歩だけは、1668本のどこにも無い。**
そして、それを書けるのは物語だけである。
朝の文章で書けば、ただ突き放したことになる。

### 傍証：一度だけ、見返りをつけなかった行

Day1643（143字・39本で最短）に、この一行がある。

```
恐れずに。

いや、恐れながらも。
```

**恐れを消していない。乗り越えてもいない。恐れたまま進めと書いている。**
39本で、負の感情を回収せずに残した唯一の場所。

**★ 理由をなのさに聞いた（2026-08-29）。編集室の推測（「短いから」）は外れ。**

> **抽象だからです。**

抽象の恐れは、誰の恐れでもない。**痛まないから、置いていける。**
具体の中では、なのさは一度も痛みを置いていけていない。

→ 詳細は `docs/12_具体と抽象.md`。**この本の技術的な中心課題。**

### そして、空白は「書けなかったもの」ではなかった

> **朝、元気づけ、勇気づけの文章ですから、心が前向きになるように、心理には触れません。**
> （なのさ・2026-08-29）

**意図的な設計だった。** だから空白は偶然ではなく、**系統的**である。
系統的な空白は、素材として信頼できる。**必ずそこに、何かが在る。**

そして——**1668本の「でも」の位置が、この本の章の位置になる**（`docs/12` 2.5）。
