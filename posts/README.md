## ここに入るもの

Day1 から現在（1193回以上）までの原文。**素材であって、原稿ではない。**
出来不出来で選別しない。すべて残す。

## 形式

50本前後ずつ、`batch-0001.md`, `batch-0002.md` … に分割して置く。
一度に全部をコンテクストへ載せないため（引き継ぎ書 PHASE 1）。

各投稿の区切りは、原則この形にする：

```markdown
## Day 412 | 2024-06-15

（本文。改行はそのまま残す）

---

## Day 413 | 2024-06-16

（本文）
```

- **本文は一字も直さない。** 誤字も改行も、そのまま。
  分析は原文に対して行う。整えるのは、本を書く段階（PHASE 9）になってから。
- Day番号や日付が不明な投稿があってもよい。`## Day ? | 2024-06-15` のように書き、
  わかる情報だけ残す。

## 一括で分割する

エクスポートした一つの大きいファイルがあるなら：

```bash
python3 tools/split_posts.py 元データ.txt --out posts/ --size 50
```

区切りの検出パターンが合わないときは `--pattern` で正規表現を渡す。
実データを見てから調整する前提のツールなので、うまく動かなくても問題ない。

## 元データについて

原本（LINE / note / メモアプリ等のエクスポート）は、
可能ならそのまま `posts/_raw/` に置いておく。分割をやり直せるようにするため。
