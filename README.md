# 心晴日和｜なのさ編集室

「心晴日和」1193本以上の朝の文章から、**一冊の物語** を発見するための作業場所。

過去投稿をきれいに並べ直す作業ではない。
文章の奥にある、**まだ言葉になっていない思想** を掘り出して、物語として組み直す。

---

## いまここ

**PHASE 1（全投稿の収集）。なのさが少しずつ原文を貼っていく形で進める。**

## 作業の流れ

```
posts/          原文（バッチ分割して置く）
   ↓  読む
analysis/records/*.jsonl    1投稿1行の分析記録（形式は analysis/schema.md）
   ↓  集計 tools/report.py
docs/03_思想地図.md          繰り返される思想と、そのつながり
   ↓
本の核を一文に → 主人公 → 物語の設計 → 書き下ろし
```

## ツール

```bash
python3 tools/split_posts.py 元データ.txt --out posts/ --size 50   # 分割
python3 tools/validate_records.py                                  # 記録の形式検査
python3 tools/report.py                                            # PHASE 3 の集計
```

`validate_records.py` は1バッチ書き終えるたびに走らせる。
1193本の途中で形式がぶれると、集計そのものが成立しなくなる。

## 急がないこと

1. いきなり本を書き始めない。
2. 数百本読んだ段階で章立てを決めない。
3. **「人生とは不幸なものである」を最初から結論に固定しない。**
   これは検証対象であって、前提ではない。反証を探す手順を分析に組み込んである。
   出どころは執行草舟の思想（`docs/07_思想の源泉_執行草舟.md`）。
   **思想の中身（断定する）と語り口（押しつけない）が正反対である**ことを、
   書きながら常に自覚する。この本が失敗するとすれば、ほぼ確実にここ。
4. 思想を勝手に決めつけない。問いながら掘り下げる。

> 「なのさが書いた文章」ではなく、
> 「なのさという人間が生きてきたことから生まれた一冊」を作る。
