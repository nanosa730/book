# 心晴日和｜なのさ編集室

「心晴日和」1193本以上の朝の文章から、**一冊の物語** を発見するための作業場所。

過去投稿をきれいに並べ直す作業ではない。

本の核は、なのさ自身の言葉でこうなっている（2026-08-29）：

> **人生は不幸でも良い。そう思えるか。**

そして重要なのは——**この核は、1193本のどこにも書かれていない。**
文字だけでは伝わらないと分かっていたから、なのさは意図的に書かなかった。

```
1193回、毎朝書いた。
そのあいだ一度も、いちばん大事なことは書かなかった。
書かなかったのではない。書けなかった。朝の短い文章では届かないから。

だから本を作る。
```

**この本は1193本の続きではない。1193本が届かなかった場所へ行くために作る。**
→ `docs/08_なぜ物語でなければならないか.md`

## 作業の流れ

```
posts/          原文（バッチ分割して置く）
   ↓  読む
analysis/records/*.jsonl    1投稿1行の分析記録（形式は analysis/schema.md）
   ↓  集計 tools/report.py
docs/03_思想地図.md          繰り返される思想と、そのつながり
   ↓
本の核を一文に → 主人公 → 物語の設計 → 書き下ろし
```

## ツール

```bash
python3 tools/split_posts.py 元データ.txt --out posts/ --size 50   # 分割
python3 tools/validate_records.py                                  # 記録の形式検査
python3 tools/report.py                                            # PHASE 3 の集計
```

`validate_records.py` は1バッチ書き終えるたびに走らせる。
1193本の途中で形式がぶれると、集計そのものが成立しなくなる。

## 急がないこと

1. いきなり本を書き始めない。
2. 数百本読んだ段階で章立てを決めない。
3. **絶対負は、伝達しない。翻訳する。**
   思想はそのまま受け取る。**語り口は一切持ち込まない。**
   執行草舟は大人に向けて断定する。なのさは13歳に向けて問いかけてきた。
   書きながら自問する：**これは執行草舟の声か、なのさの声か。**
4. **「良い」を落とさない。**
   「人生は不幸 **でも良い**」から「良い」が落ちて「人生は不幸だ」になった瞬間、
   この本は別の本になる。問いが断定に変わり、「教えない」原則が壊れる。
   **この本が失敗するとすれば、ほぼ確実にここ。**
5. 思想を勝手に決めつけない。問いながら掘り下げる。
6. **地図Aと地図Bを混ぜない**（`docs/03_思想地図.md`）。
   思想の骨格は執行草舟から来ている。1193本の根っこは、まだ一本も読んでいない。
   **二つが重なるかどうかを見るのが、このプロジェクトの山場。**

> 「なのさが書いた文章」ではなく、
> 「なのさという人間が生きてきたことから生まれた一冊」を作る。
